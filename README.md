# 🗃️ Automatic File Sorter using Python

This project is a simple Python script that automatically organizes files in a given folder by their file types. It helps keep your workspace clean by moving files into categorized subfolders like `Images`, `Videos`, `Documents`, `Audio`, and more.

## ✅ Features

- 📁 Organizes files by extension
- 🧠 Automatically creates folders if they don't exist
- 🐍 Written in plain Python using built-in libraries (`os`, `shutil`)
- 💡 Easy to customize for your own file types

## 📦 Requirements

- Python 3.x
- No external libraries needed
